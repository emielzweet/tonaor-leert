# Security policy

## Report a vulnerability

Please report security vulnerabilities through GitHub's **Report a vulnerability** flow on this repository's **Security → Advisories** page. This creates a private report for coordinated investigation and disclosure.

Do not report vulnerabilities in public issues, discussions, or pull requests. Include the affected version or commit, impact, and steps to reproduce in the private report.

If the private reporting option is unavailable, do not publish the vulnerability details. Contact the repository maintainer through an existing private channel and ask them to enable private vulnerability reporting.

The maintainer will acknowledge reports as soon as practical and coordinate any fix and disclosure with the reporter.
